# Jumper ![doodle](assets/player.png)

Простая игра в стиле `Doodle Jump`, написанная на `Python`.

## 🚀 Быстрый запуск
1. Склонируйте или скачайте репозиторий:
   ```bash
   git clone https://github.com/ChackChock/Jumper.git
   ```
1. Откройте терминал в папке с проектом
1. Запустите `main.py` или выполните команду:
   ```bash
   python main.py
   ```
1. Наслаждайтесь игрой!

## ✨ Особенности
- Полностью на Python 3.14.3
- Основной движок - `pygame-ce`
- Изображения из оригинальной игры
